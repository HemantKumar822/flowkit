# Notes evaluation app

Run `node server.mjs`, open http://127.0.0.1:4179, or run `npm test` here. This is a deliberately local, in-memory evaluation app. Restart loses notes. There is no login, durable storage, multi-user isolation or production deployment; do not expose it publicly. It demonstrates two independently owned frontend/backend tasks followed by integrated API and native-browser verification. See the repository's evaluation and screenshots.
